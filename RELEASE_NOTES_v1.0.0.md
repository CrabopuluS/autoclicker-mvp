# AutoClicker MVP v1.0.0

First public release of AutoClicker MVP for Windows.

## Highlights

- New polished desktop UI built with PySide6.
- High-speed click engine with 0 ms max-speed mode.
- Global hotkeys:
  - F6 Start
  - F7 Stop
  - F8 Pause/Resume
  - F9 Capture coordinates
- Reliable state machine (`IDLE`, `RUNNING`, `PAUSED`, `STOPPED`).
- Single-instance protection.
- Built release EXE with icon branding.

## Download

- `AutoClickerMVP-win64.zip`

## Notes

- Works on Windows 10/11 (x64).
- If an F-key is already captured by another app, hotkey registration can fail.
